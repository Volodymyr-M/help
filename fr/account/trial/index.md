# Essai gratuit

Ingantt pour Web commence par un essai gratuit de 7 jours avec un accès complet à toutes les fonctionnalités. Aucune carte bancaire n'est requise pour le démarrer.

## Démarrer l'essai

Votre essai démarre la première fois que vous vous connectez avec Google. Il n'y a rien à activer : Ingantt enregistre votre compte Google, vous envoie un e-mail de bienvenue, et vos 7 jours commencent. L'essai est lié à votre compte Google, et non à un appareil ou à un navigateur ; vous connecter sur un autre appareil poursuit donc le même essai.

## Ce qui est inclus

Tout. Aucune fonctionnalité n'est bridée pendant l'essai — la génération de projet par l'IA, l'import et l'export Microsoft Project, l'intégration Google Drive, le nivellement des ressources, les références de base et la valeur acquise fonctionnent exactement comme avec un abonnement payant.

## Suivre le temps restant

Le tiroir de navigation affiche votre statut :

- **Free trial ends in N days**
- **Free trial almost ended**
- **Free trial ended**

Vous recevez également un e-mail quelques jours avant la fin de l'essai, et un autre lorsqu'il est terminé.

## À la fin de l'essai

Ingantt passe en mode **lecture seule** et l'interface indique *View only mode as trial ended*.

- **Rien n'est supprimé.** Vos fichiers de projet restent dans votre Google Drive, exactement là où ils étaient. Ils vous appartiennent ; Ingantt ne stocke pas vos projets sur ses propres serveurs.
- Vous pouvez toujours ouvrir vos projets et les consulter.
- Vous ne pouvez pas enregistrer de modifications tant que vous n'êtes pas abonné. Si vous essayez, Ingantt vous propose la boîte de dialogue d'abonnement.
- Pour récupérer vos plannings, utilisez **File** → **Download** → **Download XML**, ou ouvrez les fichiers depuis Google Drive avec n'importe quel outil capable de lire le XML Microsoft Project.

Abonnez-vous via **Subscribe now** dans le message, ou depuis la boîte de dialogue **Account**. Voir [Abonnements et paiement](/fr/account/subscription/index.md).

## Applications installées

Cet article décrit Ingantt pour Web. Si vous avez installé Ingantt depuis l'App Store, Google Play, le Mac App Store ou le Microsoft Store, votre accès dépend de l'achat effectué dans cette boutique — voir [Abonnements et paiement](/fr/account/subscription/index.md).

## Questions sur votre essai

Pour toute question concernant la prolongation d'un essai, son redémarrage, ou un essai qui s'est terminé plus tôt que prévu : [écrivez au support](mailto:support@ingantt.com) en indiquant l'adresse du compte Google avec lequel vous vous êtes connecté, et nous examinerons le compte.
