# Contacting Support

Two items sit next to each other in the **Help** menu and they do different things.

- **Help → Contact support** opens a form inside Ingantt. It can carry your project file with it, and it tells us which platform and build you are on. This is the one to use for a problem with a plan.
- **Help → Email support** opens your own mail client addressed to `support@ingantt.com`. Use it if the app will not start, or if you would rather write from your own mailbox.

## Sending a Report from the App

**Help → Contact support** shows:

- **From** — your Google account photo, name, and email, filled in for you and not editable. You must be signed in to Google; the form does not open otherwise.
- A message box: *Describe your issue or feedback*.
- A checkbox: **Include current project file**.

Press **SEND**. On success you see *Thank you! We'll get back to you by email.* If it fails, you see *Failed to send feedback. Please try again or email us directly.* — in which case use **Email support** instead.

Your report also carries the platform, client version, and language you are running, so you do not need to describe your build.

## Include Current Project File

**The checkbox starts unticked. Tick it, or we do not receive your file.**

It is only shown when the open project has more than one task. For an empty or brand-new plan there is nothing worth sending, so the option is hidden altogether.

When you tick it, Ingantt attaches your plan as XML, named after the project. It sends the plan **as it is on screen right now**, including edits you have not saved. If you opened an `.mpp` file, what we receive is still XML — Ingantt's own format — not your original `.mpp`.

Please tick it whenever you are reporting something about a schedule. Dates, dependencies, calendars, and constraints interact, and the plan itself is usually the fastest way for us to see what you are seeing.

## Replies

We reply by email to the address shown in the **From** line of the form, so watch that mailbox. Your report does not carry a reference number — if you write to us again about the same problem, send it from the same address so we can match the two.
