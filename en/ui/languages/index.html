Languages #

Ingantt's interface is available in 16 languages. It follows the language your device or browser is set to.

Supported interface languages #

  • Chinese (Simplified)
  • English
  • French
  • German
  • Hindi
  • Indonesian
  • Italian
  • Japanese
  • Korean
  • Malay
  • Polish
  • Portuguese
  • Spanish
  • Thai
  • Turkish
  • Ukrainian

The same list applies to every platform: Web, Android, iOS, Windows, and macOS.

How Ingantt picks the language #

Ingantt reads the language setting of your device — on the web, the language your browser reports — and uses it if it is one of the languages above. There is no language setting inside Ingantt: to change the interface language, change your device's or browser's language and reopen Ingantt.

Your language also decides a few regional defaults: whether times are shown in 12-hour or 24-hour format, which day a week starts on, and which currency symbol a new project starts with. These are only starting points — Date/time format is in the Options dialog, and the week start and currency belong to the project and are set in Project Properties.

The language of your project #

The interface language and the contents of your plan are independent. Whatever language Ingantt's menus are in, you can type task names, resource names, notes, and any other text in your schedule in any language you like.

Currency and its position are set per project in Project Properties, not by the interface language. See Planning Costs.

This help centre #

This guide is published in English, German, Spanish, French, Italian, Portuguese, Ukrainian, Japanese, and Korean. Use the language switcher in the header. A few newer articles exist in English only until they are translated — switching language on one of those takes you to the start of the guide in that language instead.

If Ingantt's interface is available in your language but this guide is not, tell us — it helps us prioritise.
