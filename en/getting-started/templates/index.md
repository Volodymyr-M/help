# Project Templates

A template is a ready-made plan you copy and edit. It arrives with its tasks, durations, dependencies, and outline already in place, so you are correcting a structure rather than typing one from nothing.

## The Templates That Ship

Four templates are built in — there is nothing to download and no template store.

| Template | What it is for |
|----------|----------------|
| **Tutorial Template** | A guided plan that walks through Ingantt's features. The best first project if you are new to the app. |
| **PMI Process Template** | The PMI process groups — initiating, planning, executing, monitoring and controlling, closing — as a task outline. |
| **Software Development Plan Template** | A software delivery plan: requirements, design, build, test, release. |
| **Wedding Plan Template** | A worked non-software example with a hard deadline. |

## Starting a Plan from a Template

**From the projects screen.** The strip across the top, **Start a new project plan**, shows each template with a preview image. Click one and it opens. Next to it, the **+** card starts a **Blank project plan** instead. **Template gallery** opens the full list in a dialog, and the **⋮** menu has **Hide all templates** if you would rather not see the strip.

**From inside a project.** Choose **File → New from template**.

Either way you get a copy. The built-in template itself is never modified, so you can start from the same one as often as you like.

## Where the New Plan Is Saved

This depends on how you are running Ingantt.

- **Ingantt for Web, signed in to Google.** The new plan is written to your [Google Drive](/en/ui/files/index.md) straight away and opens in a **new browser tab**. The project you were working in stays open and untouched in the original tab. Because it is in Drive from the first moment, autosave is on immediately.
- **Everywhere else.** The plan opens as an unsaved project. It has no home until you save it, and it does not autosave until then — use **Save** or **Save as** and choose where it goes.

If the template cannot be read you see *Error loading template. Please try again.* If it cannot be written to Drive, you see *Error saving to Google Drive.* In both cases nothing has been changed and your existing project is unaffected.

## After the Template Opens

The copy is a normal project. Rename it with **File → Rename**, delete the tasks you do not need, and set the project start date in [Project Properties](/en/setting-up-project/project/index.md) — the template's dates are relative to its own start and will all shift when you change it.

Starting a new project from a template requires an active trial or subscription, the same as creating a blank one.
