Install Ingantt #

Ingantt runs in a browser and as an installed app on Android, iOS, Windows, and macOS. Install the version that matches your device — your project files are the same everywhere, because Ingantt saves in a format that is fully compatible with Microsoft Project.

Where to get Ingantt #

Platform Where to get it
Web web.ingantt.com — nothing to install
Android Google Play
iOS App Store
macOS Mac App Store
Windows Microsoft Store

Ingantt for Web is also listed on the Google Workspace Marketplace. Adding it from there is what puts Ingantt into Google Drive's New menu and into the Open with menu of your Ingantt files.

Ingantt for Web #

There is nothing to install. Open web.ingantt.com in your browser and start working.

You can use Ingantt for Web without signing in: open a project file from your device, edit it, and download the result. Signing in with Google lets Ingantt keep your projects in your Google Drive, save them as you work, and share them with other people. See Google Drive Integration.

Features that are only in Ingantt for Web #

Almost everything in this guide works on every platform. Two things do not:

  • Edit with AI is in beta and available on the web version only. See Edit with AI.
  • Sharing from inside Ingantt is available on the web version only. On the other platforms, share the file from Google Drive instead. See Sharing a Project.
