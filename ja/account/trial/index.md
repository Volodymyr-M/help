# 無料トライアル

Ingantt for Webは、すべての機能にフルアクセスできる7日間の無料トライアルから始まります。開始にクレジットカードは不要です。

## トライアルの開始

トライアルは、Googleで初めてサインインしたときに始まります。有効化の操作は不要です。InganttがあなたのGoogleアカウントを登録し、ウェルカムメールを送信すると、7日間が始まります。トライアルはデバイスやブラウザではなくGoogleアカウントに紐付けられるため、別のデバイスでサインインしても同じトライアルが継続します。

## 含まれる内容

すべてです。トライアル中に制限される機能はありません。AIによるプロジェクト生成、Microsoft Projectのインポートとエクスポート、Google Driveとの連携、リソースの平準化、ベースライン、アーンドバリューのすべてが、有料サブスクリプションとまったく同じように動作します。

## 残り日数の確認

ナビゲーションドロワーにステータスが表示されます：

- **Free trial ends in N days**
- **Free trial almost ended**
- **Free trial ended**

また、トライアル終了の数日前と、終了後にもメールが届きます。

## トライアルが終了すると

Inganttは**閲覧専用**モードに切り替わり、インターフェースに*View only mode as trial ended*と表示されます。

- **何も削除されません。** プロジェクトファイルは、Google Driveの元の場所にそのまま残ります。ファイルはあなたのものです。InganttがプロジェクトをIngantt自身のサーバーに保存することはありません。
- 引き続きプロジェクトを開いて閲覧できます。
- サブスクリプションに登録するまで、変更を保存することはできません。保存しようとすると、Inganttはサブスクリプションのダイアログを表示します。
- 計画を取り出すには、**File** → **Download** → **Download XML**を使用するか、Microsoft Project XMLを読み取れる任意のツールでGoogle Driveからファイルを開きます。

メッセージ内の**Subscribe now**、または**Account**ダイアログからサブスクリプションに登録できます。[サブスクリプションと支払い](/ja/account/subscription/index.md)をご覧ください。

## インストール版アプリ

この記事はIngantt for Webについて説明しています。App Store、Google Play、Mac App Store、またはMicrosoft StoreからInganttをインストールした場合、アクセスはそのストアでの購入によって管理されます。[サブスクリプションと支払い](/ja/account/subscription/index.md)をご覧ください。

## トライアルに関する質問

トライアルの延長や再開、予想より早く終了したトライアルなどに関するご質問は、サインインに使用したGoogleアカウントのアドレスを添えて[サポートにメール](mailto:support@ingantt.com)してください。アカウントを確認いたします。
