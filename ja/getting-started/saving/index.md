# プロジェクトの保存

Inganttは、プロジェクトをデバイス上のファイルまたはGoogle Drive上のファイルとして保存します。その後は、自動保存が作業中にそのファイルを最新の状態に保ちます。この記事では、どの保存先になるか、自動保存がいつ適用されるか、そして自動保存が機能しない唯一のケースについて説明します。

## 初めて保存する

ツールバーの**Save**ボタンをクリックするか、**File**メニューの**Save file**を使用します。

プロジェクトが一度も保存されていない場合、Inganttは保存先を尋ねます。**Save project as**では2つの保存先を選べます：

- **Save to new local file** — デバイス上のファイル。
- **Save to new Google Drive file** — Google Drive上のファイル。Googleでのサインインが必要です。

保存先は後から**File**メニューの**Save file as**で変更できます。これは常に新しいファイルを作成し、以降はそのファイルで作業を続けます。

プロジェクトはMicrosoft Projectと完全に互換性のあるXML形式で保存されます。計画のどの部分もInganttに縛られることはありません。

> Webでは、プロジェクト作成時にすでにGoogleにサインインしていれば、InganttがGoogle Driveを自動的に選択し、プロジェクト名にちなんだファイル名を付けます。自動保存が機能し始める前に一度保存する必要はなく、プロジェクト名を変更するとDriveのファイル名も変更されます。

## 自動保存

自動保存がオンの場合、Inganttは未保存の変更があるときにのみ、約20秒ごとにすべての変更をプロジェクトの既存ファイルにバックグラウンドで書き込みます。書き込み先は常にプロジェクトがすでに持っている保存先で、新しい保存先を選ぶことはありません。

デフォルトでオンかどうかはプラットフォームによって異なります：

| プラットフォーム | デフォルトの自動保存 | 変更する場所 |
|----------|--------------------|--------------------|
| **Web** | オン | **File**メニュー → **Work offline (no autosave)** |
| **Android、iOS、Windows、macOS** | オフ | **Options**ダイアログまたは**File**メニューの**Enable autosave** |

**Save**ボタンは自動保存のインジケーターも兼ねています。*Saving…*、*File saved*、*File saved to Google Drive*、*Autosave pending…*、または保存が完了しなかった場合のエラーが表示されます。

自動保存が役に立たない状況が2つあります：

- **プロジェクトが一度も保存されていない。** 更新すべきファイルがまだ存在しないため、一度自分で保存してください。
- **ブラウザでInganttを使用中に、ローカルファイルからプロジェクトを開いた。** 以下をご覧ください。

## Webでの自動保存とローカルファイル

ブラウザは、ディスクから選択したファイルに書き戻すことができません。Ingantt for Webが「ローカルファイル」に保存する場合、代わりにファイルの新しいコピーをダウンロードします。これは明示的な**Save**に対しては正しい動作ですが、20秒ごとに起きてほしいものではありません。

つまり、**Ingantt for Webはローカルファイルには自動保存しません。** ブラウザでローカルのプロジェクトファイルを開き、変更を自動的に保存したい場合は、一度**Save file as** → **Save to new Google Drive file**を使用してください。それ以降は、自動保存がDriveのファイルを最新の状態に保ちます。

これは[AIで編集](/ja/getting-started/edit-with-ai/index.md)にも同様に影響します。自動保存がない場合、AIが変更した内容はあなた自身が保存するまで未保存のままとなり、Inganttはセッション開始前にそのことを警告します。

## Webでのオフライン作業

**File**メニューの<strong>Work offline (no autosave)</strong>は、現在のブラウザタブの自動保存をオフにします。すべての変更がGoogle Driveに送られることなく編集を続けたい場合に使用します。

知っておくべき点が2つあります：

- オンの間は何も保存されないため、タブを閉じる前に手動で保存してください。オンにするとInganttがその旨を通知します。
- この設定はセッションごとです。ページを再読み込みしたり新しいタブを開いたりすると、再び自動保存がオンの状態で始まります。Android、iOS、Windows、macOSでは、代わりに**Enable autosave**の設定が記憶されます。

## コピーのダウンロード

Webでは、**File** → **Download** → **Download XML**で、プロジェクト自体の保存場所を変えることなく、プロジェクトのコピーをコンピューターに保存できます。バックアップや、Microsoft Projectを使用している相手にファイルを渡す際に使用します。

その他の形式（PDF、PNG、CSV、XML、YAML、Markdown）については、[インポートとエクスポート](/ja/getting-started/import-export/index.md)で説明しています。

## 未保存の変更がある状態で閉じる

未保存の変更があるプロジェクトを閉じると、Inganttは**Save changes to**ダイアログでプロジェクトへの変更を保存するかどうかを尋ね、未保存の変更が失われることを警告します。プロジェクトをゴミ箱に移動する前にも同じ確認が表示されます。

## Inganttで保存できない場合

- <strong>「View only mode as trial ended」</strong>または<strong>「Subscription inactive」</strong> — プロジェクトはそのまま残っており閲覧できますが、サブスクリプションが有効になるまで保存はオフになります。[無料トライアル](/ja/account/trial/index.md)と[サブスクリプションと支払い](/ja/account/subscription/index.md)をご覧ください。
- **「You are a viewer and cannot save」** — Google Driveのファイルが閲覧者またはコメント投稿者としてあなたに共有されています。オーナーに編集権限を依頼するか、**Save file as**を使用して自分のコピーを保存してください。[プロジェクトの共有](/ja/ui/sharing/index.md)をご覧ください。
- **「Error saving file to Google Drive」** — 通常は接続の問題か、Googleのサインインの期限切れです。接続を確認して再度サインインしてください。[Google Driveとの連携](/ja/ui/files/index.md)をご覧ください。
