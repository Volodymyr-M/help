# プロジェクトテンプレート

テンプレートは、コピーして編集するためのあらかじめ用意された計画です。タスク、期間、依存関係、アウトラインがすでに整った状態で提供されるため、ゼロから入力するのではなく、構造を手直しするだけで済みます。

## 組み込みのテンプレート

4つのテンプレートが組み込まれています。ダウンロードするものはなく、テンプレートストアもありません。

| テンプレート | 用途 |
|----------|----------------|
| **Tutorial Template** | Inganttの機能を順に案内するガイド付きの計画。アプリを初めて使う場合の最初のプロジェクトとして最適です。 |
| **PMI Process Template** | PMIのプロセス群（立ち上げ、計画、実行、監視・コントロール、終結）をタスクのアウトラインにしたもの。 |
| **Software Development Plan Template** | ソフトウェア開発計画：要件定義、設計、構築、テスト、リリース。 |
| **Wedding Plan Template** | 厳守すべき期限のある、ソフトウェア以外の実例。 |

## テンプレートから計画を開始する

**プロジェクト画面から。** 上部に並ぶ**Start a new project plan**の帯には、各テンプレートがプレビュー画像付きで表示されます。1つをクリックすると開きます。その隣の<strong>+</strong>カードは、代わりに**Blank project plan**を開始します。**Template gallery**はダイアログに完全な一覧を開き、<strong>⋮</strong>メニューには帯を表示したくない場合のための**Hide all templates**があります。

**プロジェクト内から。** **File → New from template**を選択します。

どちらの場合もコピーが作成されます。組み込みのテンプレート自体が変更されることはないため、同じテンプレートから何度でも開始できます。

## 新しい計画の保存先

これはInganttの実行方法によって異なります。

- **Ingantt for Webで、Googleにサインインしている場合。** 新しい計画はすぐに[Google Drive](/ja/ui/files/index.md)に書き込まれ、**新しいブラウザタブ**で開きます。作業中だったプロジェクトは元のタブで開いたまま、変更されません。最初の瞬間からDriveにあるため、自動保存はすぐに有効になります。
- **それ以外の場合。** 計画は未保存のプロジェクトとして開きます。保存するまで保存先はなく、それまで自動保存は行われません。**Save**または**Save as**を使用して保存先を選択してください。

テンプレートを読み込めない場合は<em>Error loading template. Please try again.</em>と表示されます。Driveに書き込めない場合は<em>Error saving to Google Drive.</em>と表示されます。どちらの場合も何も変更されておらず、既存のプロジェクトには影響しません。

## テンプレートが開いた後

コピーは通常のプロジェクトです。**File → Rename**で名前を変更し、不要なタスクを削除し、[プロジェクトのプロパティ](/ja/setting-up-project/project/index.md)でプロジェクトの開始日を設定してください。テンプレートの日付はそれ自身の開始日を基準にしているため、開始日を変更するとすべての日付がシフトします。

テンプレートから新しいプロジェクトを開始するには、空のプロジェクトを作成する場合と同様に、有効なトライアルまたはサブスクリプションが必要です。
