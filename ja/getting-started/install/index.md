# Ingantt for Webを開く

Ingantt for Webはブラウザで動作します。ダウンロードもインストールも不要です。[web.ingantt.com](https://web.ingantt.com){:target="_blank"}を開けば、すぐに作業を始められます。プロジェクトはMicrosoft Projectと完全に互換性のある形式で保存されるため、Microsoft Projectを使っている相手ともファイルをやり取りできます。

## アカウントの有無を問わない利用

Ingantt for Webはサインインしなくても使えます。デバイスからプロジェクトファイルを開き、編集して、結果をダウンロードできます。

Googleでサインインすると、Ingantt for WebはプロジェクトをあなたのGoogle Driveに保管し、作業中に保存し、他の人と共有できるようになります。詳しくは[Google Driveとの連携](/ja/ui/files/index.md)と[プロジェクトの共有](/ja/ui/sharing/index.md)をご覧ください。

## Ingantt for WebをGoogle Driveに追加する

Ingantt for Webは[Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"}に掲載されています。そこから追加すると、Google Driveの**New**メニューと、Inganttファイルの**Open with**メニューに**Ingantt**が表示され、Driveから直接プロジェクトを作成したり開いたりできます。詳しくは[Google Driveとの連携](/ja/ui/files/index.md)をご覧ください。
