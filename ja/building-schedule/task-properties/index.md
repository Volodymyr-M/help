# タスクのプロパティ

各タスクには、スケジューリング方法、コスト計算方法、ガントチャートでの表示方法を制御するプロパティがあります。これらは**タスクのプロパティ**ダイアログで設定します。

## 期間

プロジェクトの計画時に、期間は見積もりとして入力します。つまり、すべてのリソースが関与した場合にタスクにかかる時間の妥当な予測です。

**期間**と**作業**を混同しないでください。たとえば、3人がタスクに取り組んでいるが1時間で完了する場合、タスクの**期間**は1時間に設定します。この3人がタスクに割り当てられている場合、Inganttは**作業**プロパティを3時間として自動計算します。

期間は**タスクのプロパティ**ダイアログの**期間**フィールドで変更できます。

期間の見積もりにまだ自信がない場合は、**タスクのプロパティ**ダイアログで**見積もり**としてマークできます。これにより、期間に常に疑問符（「**?**」）が表示されます。このフラグのオン/オフはスケジューリングに影響しません。

サマリータスクの少なくとも1つのサブタスクで**見積もり**がチェックされている場合、サマリータスクの期間にも**見積もり**マークが付き、「**?**」が表示されます。

期間は時間、日、週、月の単位で設定できます。デフォルトでは、「1日」は8時間、「1週間」は5日（40時間）、「1か月」は20日を意味します。これらのデフォルトは**プロジェクトのプロパティ**ダイアログの**期間**タブで変更できます。

リソースの割り当て、作業量、または期間を変更すると、タスクの[タイプ](#タイプとエフォートドリブン)に応じていずれかが再計算されます。

## 作業量

タスクに稼働リソース（タスクを実行する人など）が割り当てられると、タスクの**作業**プロパティが0より大きくなります。これは、すべてのリソースがタスクに費やす時間を表します。たとえば、**期間**が5時間のタスクに2つの割り当てリソースがある場合、タスクの**作業**は10時間になります。

作業量は**タスクのプロパティ**ダイアログの**作業**フィールドで変更できます。

期間と同様に、作業量は**プロジェクトのプロパティ**ダイアログの**期間**タブの定義を使用して、時間、日、週、月の単位で指定できます。作業量のデフォルト表示形式は**時刻**タブで変更できます。

リソースの割り当て、作業量、または期間を変更すると、タスクの[タイプ](#タイプとエフォートドリブン)に応じていずれかが再計算されます。

## 期限

特定の日までにタスクを完了させなければならない場合があります。これは一般的に期限と呼ばれます。

タスクの期限は**タスクのプロパティ**ダイアログの**締め切り**フィールドで指定できます。

期限は参照目的のみで、スケジューリングには影響しません。

期限はガントチャートに特別なアイコンで表示されます。

> スケジュール上のタスクの終了日が指定された期限よりも遅い場合、Inganttはタスクリストにアイコンを表示し、ナビゲーションドロワーでそのようなタスクの数をカウントします。

![期限](/images/building-schedule/tasks/deadline.png)

> ルートサマリータスクに期限を設定することで、プロジェクト全体の期限を設定できます。ルートサマリータスクが**オプション**ダイアログで表示設定されていることを確認してください。

## マイルストーン

**タスクのプロパティ**ダイアログの**マイルストーン**チェックボックスにチェックを入れることで、任意のタスクをマイルストーンとしてマークできます。これにより期間やスケジューリングは変わりませんが、ガントチャートにアイコンとして表示されます。

![マイルストーン](/images/building-schedule/tasks/milestone.png)

タスクの**期間**に0を指定すると、変更を保存した時点でタスクは自動的に**マイルストーン**としてマークされます。

## タイプとエフォートドリブン

稼働リソースの割り当て（または割り当てられた稼働リソースの単位）、作業量、期間は互いに依存しています。いずれか1つを変更すると、他の値をそれに応じて再計算する必要があります。タスクの**タイプ**（**労力駆動**フラグと連携）は、残り2つのプロパティのうちどちらが変更されないかを定義し、1つだけが再計算されるようにします。

たとえば、**タイプ**を**固定単位**（デフォルト）に設定した場合、期間を変更すると作業量が自動的に再計算されます。

| タイプ               | 説明                                                                   |
|--------------------|---------------------------------------------------------|
| **固定単位**    | 期間を変更した場合：作業量が再計算されます。           |
|                    | 作業量を変更した場合：期間が再計算されます。           |
|                    | 単位を変更した場合：                                  |
|                    | - **労力駆動**が設定されている場合：期間が再計算されます。 |
|                    | - **労力駆動**が設定されていない場合：作業量が再計算されます。 |
| **固定期間** | 期間を変更した場合：作業量が再計算されます。           |
|                    | 作業量を変更した場合：単位が再計算されます。           |
|                    | 単位を変更した場合：作業量が再計算されます。           |
| **固定作業**     | 期間を変更した場合：単位が再計算されます。             |
|                    | 作業量を変更した場合：期間が再計算されます。           |
|                    | 単位を変更した場合：期間が再計算されます。             |

つまり、**タイプ**は3つのプロパティのうち1つを固定し、**労力駆動**フラグは残り2つのうち作業量を変更しないかどうかを定義します。

> **タイプ**と**労力駆動**の設定は、[サマリータスク](/ja/building-schedule/tasks/index.md#サマリータスク)では使用できません。サマリータスクは常にFixed durationで、エフォートドリブンではありません。

## メモ

**タスクのプロパティ**ダイアログの**メモ**タブにある**メモ**フィールドに任意のテキストを追加できます。タスクの説明、連絡先情報、アイデア、その他のテキストデータに使用できます。

タスクの**メモ**フィールドが入力されている場合、タスクリストにタスクの特別なアイコンが表示されます。Windows、macOS、Webでは、アイコンにマウスを合わせるとメモが表示されます。モバイルでは、**タスクのプロパティ**ダイアログを開いて完全なメモを確認してください。

## ハイパーリンク

**タスクのプロパティ**ダイアログの**メモ**タブにある**ハイパーリンク**フィールドを使用して、タスクにURLを添付できます。ハイパーリンクが設定されたタスクは、タスクリストにリンクアイコンが表示されます。リンクアイコンをクリックすると、ブラウザでURLが開きます。

## バーの非表示とロールアップ

**タスクのプロパティ**ダイアログの**表示**タブ：

- **バーを非表示** — ガントチャートでタスクのバーを非表示にしますが、タスクリストでは行が表示されたままです。非表示のバー領域でもクリックやコンテキストメニューに反応します。
- **ロールアップ** — サブタスクのバーを親のサマリータスクの行にガントチャート上で表示します。サマリータスクが折りたたまれている場合に、コンパクトなビューを提供します。

これらは**編集 > 表示**サブメニューまたは右クリックコンテキストメニューからも切り替えることができます。
