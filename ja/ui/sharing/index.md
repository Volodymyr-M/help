# プロジェクトの共有

Google Driveに保存されたInganttプロジェクトは、他のDriveファイルと同じ方法で共有できます。指定した人、組織、またはリンクを知っている全員と共有できます。Webでは、これらすべてをIngantt内から行えます。

## はじめる前に

共有はGoogle Driveのファイルでのみ機能します。Googleにサインインし、プロジェクトをDriveに保存している必要があります。デバイス上のローカルファイルにあるプロジェクトには共有するものがありません。[プロジェクトの保存](/ja/getting-started/saving/index.md)をご覧ください。

> **Share**ボタンはIngantt for Webの機能です。Android、iOS、Windows、macOSでは、代わりにGoogle Driveからファイルを共有してください。Driveを開き、Inganttファイルを見つけて、Drive自体の**Share**コマンドを使用します。権限はいずれの場合もDriveファイル上に存在するため、結果は同じです。

## 特定の人との共有

1. プロジェクトを開き、ヘッダーの**Share**をクリックするか、**File**メニューの**Share**を選択します。**Share on Google Drive**ダイアログが開きます。
2. **People with access**の下に、すでにアクセス権を持つ全員が、オーナーを先頭に表示されます。
3. **Add**をクリックし、相手のメールアドレスを入力し、付与する役割を選択して確定します。
4. ダイアログを閉じます。Inganttは新しい権限をDriveに保存し、*Access updated*と確認表示します。

役割はGoogle Driveの役割です：

| 役割 | できること |
|------|------------------|
| **Viewer** | プロジェクトを開いて閲覧できます。変更の保存はできません。 |
| **Commenter** | Viewerと同じに加え、Google Driveでファイルにコメントできます。変更の保存はできません。 |
| **Editor** | プロジェクトを開き、変更を保存できます。 |
| **Owner** | ファイルの削除とオーナー権限の移行を含む、すべての操作。 |

役割を変更するには、相手の名前の隣で別の役割を選択します。削除するには、その行を削除します。

> 相手が実際にGoogleにサインインできるアドレスを入力してください。アドレスがGmailまたはGoogle Workspaceのものであることを確認できない場合、Inganttは警告します。Googleアカウントのないアドレスに対するDrive共有では、相手はプロジェクトを開けないためです。

## 一般的なアクセス — リンクと組織

**General access**は、個別に指定していない全員を制御します：

- **Restricted** — **People with access**に一覧表示されている人のみ。これがデフォルトです。
- **Anyone with the link** — リンクを知っている人なら誰でも。役割（Viewer、Commenter、またはEditor）を選択します。
- **Domain** — Google Workspace組織の全員。役割を選択します。このオプションは、プロジェクトのオーナーがWorkspaceドメインに属している場合にのみ表示され、個人のGmailアカウントでは提供されません。

**Copy link**は、プロジェクトへのGoogle Driveリンクをコピーします。アクセス権が許す人なら誰でも、そのリンクを開いてInganttで計画を編集できます。

**Share**ボタンのツールチップで現在の状態が一目でわかります。*Private — only you can access*、*Shared with specific people*、*Anyone with the link can view/comment/edit*、またはドメインに対する同等の表示です。

## アクセス権を変更できる人

ファイルの**オーナー**だけが、常にアクセス権を管理できます。**編集者**もアクセス権を管理できますが、オーナーがGoogle Driveでそれをオフにしている場合は除きます。

閲覧者またはコメント投稿者として共有されたプロジェクトでダイアログを開くと、**You are a viewer and cannot manage access**と表示され、現在の一般的なアクセスは表示されますが変更はできません。さらに権限が必要な場合はオーナーに依頼してください。

## 共有プロジェクトでの作業

- 全員が同じDriveファイルを開きますが、Inganttはリアルタイム共同編集ツールではありません。保存のたびにプロジェクトファイル全体が書き込まれるため、2人が計画を開いて両方が保存すると、最後の保存が優先され、もう一方の変更は置き換えられます。開始前に誰が編集するかを決め、何かが失われたと思われる場合はGoogle Driveでファイルのバージョン履歴を確認してください。
- 閲覧者またはコメント投稿者が保存しようとすると、**You are a viewer and cannot save**と表示されます。代わりに**Save file as**を使用して個人用のコピーを保存してください。
- 編集するには、各共同作業者に有効なInganttのサブスクリプションまたはトライアルが必要です。計画を共有してもサブスクリプションは共有されません。[サブスクリプションと支払い](/ja/account/subscription/index.md)をご覧ください。
- Google**グループ**のアドレスへの共有は、InganttのShareダイアログではサポートされていません。個別のアドレスと共有するか、Google Driveからグループ共有を管理してください。
