# バージョン履歴

Inganttは、Google Driveに保存されたすべての計画の完全な履歴を保持します。履歴を閲覧し、過去の任意のバージョンをガントチャートでプレビューし、重要なものを固定し、いずれかを現在の計画として復元できます。

**プロジェクトはGoogle Driveから開いている必要があります。** バージョン履歴はGoogle Driveの変更履歴であるため、デバイスから開いたプロジェクトや一度も保存されていないプロジェクトでは、2つのバージョン履歴メニュー項目が非表示になります。[Drive](/ja/ui/files/index.md)に保存すると表示されます。

## バージョン履歴を開く

**ファイル → バージョン履歴 → バージョン履歴を表示**を選択するか、`Ctrl` + `Alt` + `Shift` + `H`を押します。

パネルがサイドに開き、チャートのスペースを確保するためにInganttが全画面表示に切り替わります。パネルを閉じると、すべて元の状態に戻ります。

## 閲覧とプレビュー

バージョンは新しい順に一覧表示され、**今日**、**昨日**、それ以降は日付で日ごとにグループ化されます。最新のものには**現在のバージョン**とラベルが付き、パネルを開くと自動的に選択されます。

任意のバージョンをクリックすると、Inganttがそれをチャートに読み込んで確認できます。プレビューは閲覧であり、編集ではありません：

- 開いている計画は、元に戻す履歴や未保存の変更を含め、手を付けられずに保持されます。
- パネルを閉じると、計画は離れたときとまったく同じ状態で戻ります。
- プレビューによってDriveに書き込まれるものはありません。

## バージョンの固定

Google Driveは、時間の経過とともにファイルの古いバージョンを整理します。バージョンを固定すると**keep forever**のマークが付き、この整理を免れて一覧に残り続けます。

固定する方法は2つあります：

- **ファイル → バージョン履歴 → 現在のバージョンを固定**は、パネルを開かずに最新バージョンを固定します。再計画の前、フェーズの終わり、計画の承認時など、残しておきたい保存の直後に使用してください。
- パネルで任意のバージョンのメニューを開き、**このバージョンを固定**を選択します。

固定されたバージョンは一覧に**固定済み**と表示されます。同じメニュー項目をもう一度選択すると固定が解除されます。

## バージョンの復元

目的のバージョンを選択し、**このバージョンを復元**を選択します。Inganttは確認を求めます：

> このバージョンを復元しますか？現在のバージョンが先に保存されます。

復元しても現在の計画が破棄されるわけではありません。復元した内容は履歴の上に**新しい**バージョンとして保存されるため、復元前のバージョンも一覧に残り、それ自体を復元することもできます。履歴は増えるだけで、復元によって何かが削除されることはありません。

確認すると、復元された計画が開いているプロジェクトになり、すぐにDriveに保存されます。

## バージョン履歴はベースラインとは異なります

この2つは混同されやすいものです：

- **バージョン履歴**は、Google Driveが保持する*ファイル*の経時的な記録です。「先週の火曜日にこの計画はどうなっていたか？」という問いに答えます。
- <strong>[ベースライン](/ja/tracking/baselines/index.md)</strong>は、計画の内部に保存された*スケジュール*のスナップショットで、同じビューで比較できます。ガントチャートのベースラインバー、テーブルのベースライン列と差異列です。「承認された計画からどれだけずれたか？」という問いに答えます。

過去に戻るにはバージョン履歴を使用します。測定にはベースラインを使用します。
