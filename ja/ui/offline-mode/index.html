サポートに問い合わせ

オフラインでの作業 #

自動保存をオフにして、意図的に保存するまでGoogle Driveに何も書き込まれないようにします。接続が切れそうなときに便利です。

Web版では、メニュー項目はファイル → オフラインで作業 (自動保存なし)です。Windows、macOS、Android、iOSでは、同じスイッチが自動保存を有効にするという名前になっています。

Work offlineの機能 #

File → Work offlineは、現在のタブの自動保存をオフにします。それがすべてです。オンの間、Inganttは20秒ごとにプロジェクトをGoogle Driveに書き込むのをやめ、保存するまでブラウザから何も送信されません。

オンにすると、一度だけ注意が表示されます：

オフラインモードがオンです。タブを閉じる前に、変更を手動で保存することを忘れないでください。

これは文字どおりに受け取ってください。Inganttは編集内容をキューに入れることはなく、オンラインに戻ったときに送信することもありません。 バックグラウンド同期はありません。保存せずにタブを閉じたり再読み込みしたりすると、最後の保存以降の作業は失われます。

オフライン中の保存 #

接続がなければGoogle Driveに保存できないため、うまくいく手順は次のとおりです：

  1. まだ接続があるうちに計画を開きます。
  2. File → Work offlineをオンにします。
  3. 通常どおり編集します。すべてはブラウザ内で行われます。スケジュールは再計算され、元に戻す／やり直しも機能し、どこにも何も送信されません。
  4. オンラインに戻ったら、Work offlineをオフに戻し、保存を押します（またはCtrl/Cmd + S）。この手順で作業がDriveに保存されます。
  5. この時点から自動保存が再開されます。

手順4を覚えておくことに頼りたくない場合は、接続が切れる前にコピーをエクスポートしてください。ファイル → エクスポート → XMLで計画がデバイスにダウンロードされ、後でそのファイルを再び開くことができます。

Saveボタンが現在の状態を示す #

ツールバーのSaveボタンが注目すべきインジケーターです：

表示 意味
Googleドライブに保存されました すべてDriveに保存されています。
自動保存が保留中... 未保存の編集があり、まもなく自動保存が行われます。
保存中... 保存が進行中です。
Googleドライブに保存 未保存の編集があり、自動保存がオフです。保存が必要です。
Googleドライブに保存する際のエラー 保存が試みられ、失敗しました。編集内容はまだタブ内にあり、未保存のままです。

接続が切れている間に自動保存が実行されると、このエラー状態が表示されます。保存は失敗し、ボタンは赤くなり、プロジェクトはタブ内で未保存のままになります。その時点で失われるものはありませんが、安全でもありません。再接続して保存してください。

プラットフォームによる違い #

  • Webではこの設定は保持されません。 タブごと、セッションごとの設定です。新しいタブを開いたり再読み込みしたりすると、自動保存は再びオンになります。これは意図的なものです。自動保存オンのほうが安全なデフォルトであり、オフラインスイッチの切り忘れが付いて回ることがないようにしています。Windows、macOS、Android、iOSでは、自動保存の設定は記憶されます。
  • デフォルトが異なります。 Webでは、自動保存は初期状態でオンです。デスクトップ版とモバイル版では初期状態でオフで、同じメニュー項目が自動保存を有効にすると表示されます。
  • まだ保存していないプロジェクトは、オフラインモードであるかどうかにかかわらず、まったく自動保存されません。 自動保存は、Driveにすでに存在するファイルしか更新できません。一度保存すれば、あとは自動保存が引き継ぎます。
  • Web版でデバイスから開いたファイルは、決して自動保存されません。 Ingantt for Webはディスク上のファイルに書き戻すことができません。自動保存を利用するには、Google Driveに保存してください。

オフラインでの作業とAIで編集 #

自動保存がオフの状態でAIで編集を使用すると、Inganttが警告します。AIの変更は、通常の元に戻せる編集として開いているプロジェクトに適用され、自動的には保存されません。保存せずにタブを閉じると、手動の編集とまったく同じように、AIの作業も失われます。

サポートされていないこと #

期待値をはっきりさせておくために：

  • Inganttは、オフラインになったことやオンラインに戻ったことを検出しません。
  • Inganttは、オフラインで行った編集をキューに入れて再接続時に再生することはありません。
  • 同期がないため、同期の競合解決もありません。あなたと同僚が同じDriveファイルを編集した場合、最後の保存が優先されます。タスクごとにマージされるのではなく、ファイル全体が置き換えられます。
  • 計画を初めて開くには接続が必要です。オフラインでの作業は、すでに開いている計画を編集可能に保つものであり、新しい計画を開けるようにするものではありません。
