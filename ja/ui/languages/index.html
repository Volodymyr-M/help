言語 #

Inganttのインターフェースは16の言語で利用できます。デバイスまたはブラウザに設定された言語に従います。

対応しているインターフェース言語 #

  • 中国語（簡体字）
  • 英語
  • フランス語
  • ドイツ語
  • ヒンディー語
  • インドネシア語
  • イタリア語
  • 日本語
  • 韓国語
  • マレー語
  • ポーランド語
  • ポルトガル語
  • スペイン語
  • タイ語
  • トルコ語
  • ウクライナ語

同じ一覧が、Web、Android、iOS、Windows、macOSのすべてのプラットフォームに適用されます。

Inganttが言語を選ぶ仕組み #

Inganttはデバイスの言語設定（Webではブラウザが報告する言語）を読み取り、それが上記の言語のいずれかであればその言語を使用します。Ingantt内に言語設定はありません。インターフェースの言語を変更するには、デバイスまたはブラウザの言語を変更してInganttを開き直してください。

言語はいくつかの地域的なデフォルトも決定します。時刻を12時間形式と24時間形式のどちらで表示するか、週の始まりを何曜日にするか、新しいプロジェクトがどの通貨記号で始まるかなどです。これらはあくまで初期値です。Date/time formatはOptionsダイアログにあり、週の開始曜日と通貨はプロジェクトに属し、Project Propertiesで設定します。

プロジェクトの言語 #

インターフェースの言語と計画の内容は独立しています。Inganttのメニューがどの言語であっても、タスク名、リソース名、メモ、その他スケジュール内のテキストは好きな言語で入力できます。

通貨とその位置は、インターフェースの言語ではなく、Project Propertiesでプロジェクトごとに設定します。コストの理解をご覧ください。

このヘルプセンター #

このガイドは、英語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語、ウクライナ語、日本語、韓国語で公開されています。ヘッダーの言語切り替えを使用してください。新しい記事の一部は、翻訳されるまで英語のみで提供されます。そのような記事で言語を切り替えると、代わりにその言語のガイドの先頭に移動します。

Inganttのインターフェースはあなたの言語で利用できるのにこのガイドがそうでない場合は、お知らせください。優先順位を決める際の参考になります。
