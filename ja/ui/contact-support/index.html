サポートに問い合わせ

サポートへの問い合わせ #

ヘルプメニューには2つの項目が並んでいますが、それぞれ役割が異なります。

  • ヘルプ → サポートに連絡は、Ingantt内のフォームを開きます。プロジェクトファイルを添付でき、使用中のプラットフォームとビルドも私たちに伝わります。計画に関する問題にはこちらを使用してください。
  • ヘルプ → メールサポートは、support@ingantt.com宛てにあなた自身のメールクライアントを開きます。アプリが起動しない場合や、自分のメールボックスから書きたい場合に使用してください。

アプリからレポートを送信する #

ヘルプ → サポートに連絡には以下が表示されます：

  • 送信者 — Googleアカウントの写真、名前、メールアドレス。自動入力され、編集はできません。Googleにサインインしている必要があり、サインインしていない場合フォームは開きません。
  • メッセージ欄：問題やフィードバックを記入してください。
  • チェックボックス：現在のプロジェクトファイルを含める。

送信を押します。成功するとありがとうございます！メールにてご返信いたします。と表示されます。失敗した場合は送信に失敗しました。再試行するか、直接メールでお問い合わせください。と表示されるので、その場合は代わりにメールサポートを使用してください。

レポートには、使用中のプラットフォーム、クライアントのバージョン、言語も含まれるため、ビルドについて説明する必要はありません。

現在のプロジェクトファイルを含める #

チェックボックスは最初はオフになっています。チェックを入れないと、ファイルは私たちに届きません。

このチェックボックスは、開いているプロジェクトに複数のタスクがある場合にのみ表示されます。空の計画や作成したばかりの計画には送る価値のあるものがないため、オプション自体が非表示になります。

チェックを入れると、Inganttはプロジェクト名を付けたXMLとして計画を添付します。送信されるのは、未保存の編集を含む今まさに画面に表示されている状態の計画です。.mppファイルを開いていた場合でも、私たちが受け取るのは元の.mppではなく、Ingantt独自の形式であるXMLです。

スケジュールに関する報告をする際は、必ずチェックを入れてください。日付、依存関係、カレンダー、制約は互いに影響し合うため、計画そのものが、あなたが見ているものを私たちが把握する最も早い方法であることがほとんどです。

返信 #

返信は、フォームの送信者行に表示されているアドレス宛にメールでお送りしますので、そのメールボックスをご確認ください。レポートには参照番号が付きません。同じ問題について再度ご連絡いただく際は、2つを照合できるよう同じアドレスから送信してください。
