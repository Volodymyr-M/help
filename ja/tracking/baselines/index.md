# ベースライン

作業を開始する前にスケジュールのスナップショットを保存し、現在の状態と比較することで、プロジェクトのどこにずれが生じたかを確認できます。

ベースラインは、ある時点でのすべてのタスクの開始日、終了日、期間、作業量、コストを記録します。

## ベースラインの設定

**プロジェクト**メニューの**基準計画を設定**サブメニューからベースラインを設定します：

- すべてのタスクまたは選択したタスクのみにベースラインを設定できます。
- Inganttは最大11のベースラインをサポートしています。

## ベースラインの表示

ベースラインが保存されると、**基準計画**ダイアログでベースラインの表示/非表示を切り替えて、ガントチャートで確認できます。ベースラインバーは、現在のタスクバーの下に、ベースライン番号ごとに異なる色の細いバーとして表示されます。

ベースラインを管理するには、**プロジェクト**メニューの**基準計画**項目を使用します。**基準計画**ダイアログでは以下を行えます：

- 保存されたすべてのベースラインの表示
- 不要になったベースラインの削除
- [アーンドバリュー](/ja/tracking/earned-value/index.md#アーンドバリューマネジメント)計算に使用するベースラインの指定

## ベースラインと差異の列

**オプション**ダイアログを通じて、ベースライン列と差異列をタスクリストに追加できます。合計で**55のベースライン列**と**5つの差異列**があります。

### 55のベースライン列

Inganttは**11のベースライン**を保存します：番号なしの**基準計画**と、**基準計画 1**から**基準計画 10**までです。それぞれに同じ5つのタスク列があります：

- Baseline Start
- Baseline Finish
- Baseline Duration
- Baseline Work
- Baseline Cost

11ベースライン × 5フィールド = **55のベースライン列**で、すべてタスクテーブルの列選択から利用できます。番号なしのセットは単純な名前（*基準計画の開始*）で、番号付きのセットには番号が付きます（*基準計画 3 開始*）。

### 5つの差異列

差異列は計算値（現在のスケジュール − ベースライン）で、次の5つがあります：

- Start Variance
- Finish Variance
- Duration Variance
- Work Variance
- Cost Variance

5つの列は1セットのみで、ベースラインごとにセットがあるわけではありません。差異列は、現在のスケジュールを**1つ**のベースライン、つまり**プロジェクト → アーンドバリューオプション**で[アーンドバリューベースライン](/ja/tracking/earned-value/index.md#アーンドバリューベースライン)として選択されているベースライン（デフォルトは番号なしのBaseline）と比較します。この設定を変更すると、すべての差異列が選択したベースラインに対して再計算されます。選択したベースラインが設定されていないタスクでは、差異はゼロではなく空欄になります。

## ベースラインの保存場所

ベースラインは別のファイルではなく、**プロジェクトファイルの内部**に保存されます。プロジェクトを保存すると、そのベースラインも保存されます。

12個目のベースラインを設定しようとすると、Inganttは<em>すべてのベースラインスロットが使用中です。先にベースラインダイアログで1つ削除してください。</em>と表示します。**プロジェクト → 基準計画**を開いて、いずれかをクリアしてください。

ベースラインは、ファイル自体の経時的な記録である[バージョン履歴](/ja/ui/version-history/index.md)とは異なります。以前の計画に戻すにはバージョン履歴を、現在の計画がどれだけずれたかを測定するにはベースラインを使用してください。

## 中間計画

中間計画は、完全なベースラインのオーバーヘッドなしに簡単に比較できる、軽量なスケジュールスナップショット（**開始**と**終了**の日付のみ）を保存します。Inganttは最大10の中間計画（`Interim Plan 1`から`Interim Plan 10`）をサポートしています。

中間計画の設定とクリアは、**プロジェクト**メニューの**中間計画**項目から行います。タスクリストに中間計画の日付を列として表示できます。
