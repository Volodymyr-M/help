# WBSコード

すべてのタスクには**WBS**コードがあります。これはアウトライン内でのタスクの所在を示すものです。初期状態では、`1`、`1.1`、`1.2`、`1.2.1`のような単純なアウトライン番号です。タスクテーブルで**WBS**列をオンにすると表示されます。

**WBSコードマスク**は、これらのアウトライン番号を独自に設計した構造化コードに置き換えます。これにより、タスクは`1.1.1`ではなく`PROJ-A-01`や`1.A.001`のように表示されます。契約、コストコード体系、顧客の報告形式など、番号付けの標準を持つ組織は、Inganttのコードをその標準に合わせるためにこれを使用します。

設定するには、**プロジェクト → WBSコードの定義**を開きます。

## WBSコードとアウトラインコードの違い

- **WBSコード**は構造的なものです。タスクごとに1つだけ存在し、アウトライン内でのタスクの位置から導出されます。タスクを移動すると自動的に番号が振り直されます。
- <strong>[アウトラインコード](/ja/adjusting-schedule/custom-fields/index.md)</strong>はタグです。部門、フェーズ、コストセンターなどのルックアップリストを定義し、階層とは無関係にタスクに値を割り当てます。1つのタスクは、複数のアウトラインコードから複数の値を持つことができます。

## マスクの定義

ダイアログは3つの部分で構成されています。

### プロジェクトコードのプレフィックス

プロジェクト内のすべてのコードの先頭に付く固定テキストです。プレフィックスを`PROJ`にすると、区切り文字に応じて`PROJ.1.1`や`PROJ-A-01`のようなコードになります。プレフィックスを付けない場合は空のままにします。

### コードマスク

アウトラインレベルごとに1行で、**レベルを追加**で追加します。各行では以下を設定します：

| フィールド | 機能 |
|-------|--------------|
| **レベル** | この行が適用されるアウトラインの深さ。レベル1は最上位のタスク、レベル2はその子タスク、というように続きます。 |
| **シーケンス** | このレベルで使用する文字：**数字**（1、2、3）、**大文字**（A、B、C … Z、AA）、**小文字**（a、b、c … z、aa）、または**文字**。 |
| **長さ** | このレベルの最大文字数。空のままにすると*任意*と表示され、制限なしになります。 |
| **区切り文字** | このレベルと次のレベルの間の文字（`.`や`-`など）。 |

フィールドの動作について知っておくべき点が2つあります：

- **Lengthは数字の先頭をゼロで埋めます。** Numbersレベルで長さを`3`にすると、9番目のタスクは`009`になります。文字のレベルは埋められません。
- **文字**は、Inganttが生成するコードではNumbersと同じように動作します。これはMicrosoft Projectとの互換性のために存在するもので、Microsoft Projectでは自分で入力するレベルを意味します。

すべてのレベルを定義する必要はありません。**マスクの最後の行より深いレベルは、`.`区切りの数字にフォールバックする**ため、5階層の計画に3行のマスクを適用しても完全なコードが生成されます。

### オプション

**新しいタスクのWBSコードを生成**と**新しいWBSコードの一意性を確認**はプロジェクトとともに保存され、Microsoft Projectとのラウンドトリップでも保持されます。Inganttでは、少なくとも1つのレベルを持つマスクはすべてのタスクに自動的に適用され、コードはアウトラインに従うため構造上一意になります。

## マスクを保存すると何が起こるか

Inganttはプロジェクト全体の番号をすぐに振り直します。コードは、タスクの追加、削除、インデント、アウトデント、移動など、構造が変わるたびにアウトラインから再構築されるため、常にタスクの現在の位置を表します。

はっきり言っておくべきことがあります：**WBSコードはタスクの永続的な識別子ではありません。** タスクを移動すると、そのコードは変わります。タスクに付いて回るラベルが必要な場合は、代わりにアウトラインコードまたは[カスタムテキストフィールド](/ja/adjusting-schedule/custom-fields/index.md)を使用してください。

## インポートとエクスポート

マスクはMicrosoft Project形式の一部であり、ラウンドトリップでも保持されます。マスク付きでインポートされたプロジェクトはマスクを保持したままエクスポートされ、そのタスクコードはMicrosoft Projectが生成したものと一致します。
