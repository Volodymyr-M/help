# Освоєний обсяг

Управління освоєним обсягом (УОО) поєднує вимірювання обсягу, розкладу та вартості для оцінки того, чи проект вкладається в графік та бюджет. Встановіть дату стану та базовий план, і Ingantt розрахує стандартні галузеві метрики УОО.

## Дата стану

**Дата стану** визначає дату, що використовується для відстеження прогресу та розрахунків освоєного обсягу. Коли встановлена, на діаграмі Ганта відображається зелена вертикальна лінія на цій даті.

Коли дата стану не встановлена, для розрахунків використовується поточна дата. Ви можете встановити дату стану в діалозі **Параметри освоєного обсягу**, доступному з меню **Проєкт**.

## Управління освоєним обсягом

Ingantt підтримує управління освоєним обсягом — методику управління проектами, що інтегрує дані обсягу, розкладу та вартості для оцінки ефективності проекту.

### Налаштування освоєного обсягу

1. Створіть [базовий план](/uk/tracking/baselines/index.md#збереження-базового-плану) для фіксації запланованого розкладу та витрат.
2. Встановіть значення **Дата стану** в діалозі **Параметри освоєного обсягу** (доступному з меню **Проєкт**) або залиште стандартне значення — поточну дату.
3. Оновлюйте значення [% виконання](/uk/tracking/progress/index.md#-виконання) завдань у міру виконання робіт.

### Доступні метрики УОО

Наступні стовпці УОО можна додати до списку завдань через діалог **Параметри**:

| Метрика | Опис |
|---------|------|
| **BCWS** | Бюджетна вартість запланованої роботи (Планова вартість) |
| **BCWP** | Бюджетна вартість виконаної роботи (Освоєний обсяг) |
| **ACWP** | Фактична вартість виконаної роботи |
| **BAC** | Бюджет по завершенні |
| **EAC** | Оцінка по завершенні |
| **VAC** | Відхилення по завершенні |
| **SV** | Відхилення розкладу |
| **CV** | Відхилення вартості |
| **SPI** | Індекс виконання розкладу |
| **CPI** | Індекс виконання вартості |
| **TCPI** | Індекс виконання до завершення |
| **SV%** | Відхилення розкладу у відсотках |
| **CV%** | Відхилення вартості у відсотках |

### Метод освоєного обсягу

Кожне завдання може використовувати один із двох методів для розрахунку BCWP (Освоєного обсягу):

- **% виконання** (за замовчуванням) — Використовує відсоток виконання завдання для розрахунку освоєного обсягу.
- **Фізичний % виконання** — Використовує окремо відстежуваний фізичний відсоток виконання. Корисний для вимірювання прогресу на основі результатів.

Встановіть метод для окремих завдань на вкладці **Вартість** діалогу **Властивості завдання**. Змініть стандартний метод для нових завдань у діалозі **Параметри освоєного обсягу**.

### Базовий план для освоєного обсягу

Розрахунки УОО використовують конкретний базовий план. Ви можете обрати, який базовий план (від `Базовий план 0` до `Базовий план 10`) використовується для освоєного обсягу в діалозі **Параметри освоєного обсягу**. За замовчуванням використовується `Базовий план 0`.
