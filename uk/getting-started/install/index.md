# Відкрити Ingantt для Web

Ingantt для Web працює у вашому браузері. Нічого не потрібно завантажувати чи встановлювати: відкрийте [web.ingantt.com](https://web.ingantt.com){:target="_blank"} і починайте працювати. Ваші проекти зберігаються у форматі, повністю сумісному з Microsoft Project, тож ви можете обмінюватися файлами з будь-ким, хто ним користується.

## Вхід через Google

Якщо ви увійдете через Google, Ingantt для Web триматиме ваші проекти у вашому Google Drive, зберігатиме їх під час роботи та дозволить надавати до них доступ іншим людям. Див. [Інтеграція з Google Drive](/uk/ui/files/index.md) та [Спільний доступ до проекту](/uk/ui/sharing/index.md).

## Додавання Ingantt для Web до Google Drive

Ingantt для Web розміщено в [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"}. Додати його звідти — один зі способів зробити так, щоб **Ingantt** з'явився в меню **Створити** у Google Drive та в меню **Відкрити за допомогою** ваших файлів Ingantt, і ви могли створювати й відкривати проекти безпосередньо з Drive. Вхід в Ingantt для Web і надання дозволу **Підключення до вашого Google Drive** дає той самий результат. Докладніше див. [Інтеграція з Google Drive](/uk/ui/files/index.md).
