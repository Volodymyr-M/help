Modelos de Projeto #

Um modelo é um plano pronto que você copia e edita. Ele vem com tarefas, durações, dependências e estrutura de tópicos já definidas, então você está corrigindo uma estrutura em vez de digitar uma do zero.

Os Modelos Incluídos #

Quatro modelos são integrados — não há nada para baixar nem uma loja de modelos.

Modelo Para que serve
Tutorial Template Um plano guiado que percorre as funcionalidades do Ingantt. O melhor primeiro projeto se você é novo no aplicativo.
PMI Process Template Os grupos de processos do PMI — iniciação, planejamento, execução, monitoramento e controle, encerramento — como uma estrutura de tarefas.
Software Development Plan Template Um plano de entrega de software: requisitos, design, construção, testes, lançamento.
Wedding Plan Template Um exemplo prático fora da área de software, com um prazo fixo.

Iniciando um Plano a partir de um Modelo #

Pela tela de projetos. A faixa no topo, Start a new project plan, mostra cada modelo com uma imagem de pré-visualização. Clique em um e ele é aberto. Ao lado, o cartão + inicia um Blank project plan. Template gallery abre a lista completa em uma caixa de diálogo, e o menu ⋮ tem Hide all templates caso você prefira não ver a faixa.

De dentro de um projeto. Escolha File → New from template.

De qualquer forma, você obtém uma cópia. O modelo integrado em si nunca é modificado, então você pode começar a partir do mesmo modelo quantas vezes quiser.

Onde o Novo Plano É Salvo #

Isso depende de como você está executando o Ingantt.

  • Ingantt para Web, com login no Google. O novo plano é gravado no seu Google Drive imediatamente e é aberto em uma nova aba do navegador. O projeto em que você estava trabalhando permanece aberto e intacto na aba original. Como ele está no Drive desde o primeiro momento, o salvamento automático fica ativado imediatamente.
  • Em todos os outros casos. O plano é aberto como um projeto não salvo. Ele não tem um lugar até que você o salve, e não é salvo automaticamente até lá — use Save ou Save as e escolha onde ele fica.

Se o modelo não puder ser lido, você verá Error loading template. Please try again. Se ele não puder ser gravado no Drive, você verá Error saving to Google Drive. Em ambos os casos, nada foi alterado e seu projeto existente não é afetado.

Depois que o Modelo É Aberto #

A cópia é um projeto normal. Renomeie-a com File → Rename, exclua as tarefas de que não precisa e defina a data de início do projeto em Propriedades do Projeto — as datas do modelo são relativas ao seu próprio início e serão todas deslocadas quando você a alterar.

Iniciar um novo projeto a partir de um modelo requer uma avaliação ou assinatura ativa, assim como criar um em branco.
