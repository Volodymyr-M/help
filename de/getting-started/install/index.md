# Ingantt für Web öffnen

Ingantt für Web läuft in Ihrem Browser. Es gibt nichts herunterzuladen und nichts zu installieren: Öffnen Sie [web.ingantt.com](https://web.ingantt.com){:target="_blank"} und legen Sie los. Ihre Projekte werden in einem Format gespeichert, das vollständig mit Microsoft Project kompatibel ist, sodass Sie Dateien mit allen austauschen können, die damit arbeiten.

## Arbeiten mit oder ohne Konto

Sie können Ingantt für Web ohne Anmeldung verwenden: Öffnen Sie eine Projektdatei von Ihrem Gerät, bearbeiten Sie sie und laden Sie das Ergebnis herunter.

Wenn Sie sich mit Google anmelden, kann Ingantt für Web Ihre Projekte in Ihrem Google Drive ablegen, sie während der Arbeit speichern und sie für andere Personen freigeben. Siehe [Google-Drive-Integration](/de/ui/files/index.md) und [Projekt freigeben](/de/ui/sharing/index.md).

## Ingantt für Web zu Google Drive hinzufügen

Ingantt für Web ist im [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"} gelistet. Wenn Sie es von dort hinzufügen, erscheint **Ingantt** im Menü **Neu** von Google Drive und im Menü **Öffnen mit** Ihrer Ingantt-Dateien, sodass Sie Projekte direkt aus Drive erstellen und öffnen können. Details finden Sie unter [Google-Drive-Integration](/de/ui/files/index.md).
