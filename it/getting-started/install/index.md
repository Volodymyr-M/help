# Aprire Ingantt per Web

Ingantt per Web funziona nel tuo browser. Non c'è nulla da scaricare né da installare: apri [web.ingantt.com](https://web.ingantt.com){:target="_blank"} e inizia a lavorare. I tuoi progetti vengono salvati in un formato pienamente compatibile con Microsoft Project, così puoi scambiare file con chiunque lo utilizzi.

## Accedere con Google

Accedendo con Google, Ingantt per Web può conservare i tuoi progetti nel tuo Google Drive, salvarli mentre lavori e condividerli con altre persone. Vedi [Integrazione con Google Drive](/it/ui/files/index.md) e [Condividere un progetto](/it/ui/sharing/index.md).

## Aggiungere Ingantt per Web a Google Drive

Ingantt per Web è disponibile sul [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"}. Aggiungerlo da lì è un modo per far comparire **Ingantt** nel menu **Nuovo** di Google Drive e nel menu **Apri con** dei tuoi file Ingantt, così puoi creare e aprire progetti direttamente da Drive. Accedere a Ingantt per Web e concedere l'autorizzazione **Collegarsi al tuo Google Drive** produce lo stesso risultato. Vedi [Integrazione con Google Drive](/it/ui/files/index.md) per i dettagli.
