# Abrir Ingantt para Web

Ingantt para Web se ejecuta en su navegador. No hay nada que descargar ni instalar: abra [web.ingantt.com](https://web.ingantt.com){:target="_blank"} y empiece a trabajar. Sus proyectos se guardan en un formato totalmente compatible con Microsoft Project, por lo que puede intercambiar archivos con cualquiera que lo utilice.

## Trabajar con o sin cuenta

Puede usar Ingantt para Web sin iniciar sesión: abra un archivo de proyecto desde su dispositivo, edítelo y descargue el resultado.

Iniciar sesión con Google permite que Ingantt para Web conserve sus proyectos en su Google Drive, los guarde mientras trabaja y los comparta con otras personas. Consulte [Integración con Google Drive](/es/ui/files/index.md) y [Compartir un proyecto](/es/ui/sharing/index.md).

## Agregar Ingantt para Web a Google Drive

Ingantt para Web está disponible en [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"}. Al agregarlo desde allí, **Ingantt** aparece en el menú **Nuevo** de Google Drive y en el menú **Abrir con** de sus archivos de Ingantt, de modo que puede crear y abrir proyectos directamente desde Drive. Consulte [Integración con Google Drive](/es/ui/files/index.md) para más detalles.
