지원 문의

언어 #

Ingantt의 인터페이스는 16개 언어로 제공됩니다. 기기 또는 브라우저에 설정된 언어를 따릅니다.

지원되는 인터페이스 언어 #

  • 중국어(간체)
  • 영어
  • 프랑스어
  • 독일어
  • 힌디어
  • 인도네시아어
  • 이탈리아어
  • 일본어
  • 한국어
  • 말레이어
  • 폴란드어
  • 포르투갈어
  • 스페인어
  • 태국어
  • 터키어
  • 우크라이나어

같은 목록이 Web, Android, iOS, Windows, macOS 등 모든 플랫폼에 적용됩니다.

Ingantt가 언어를 선택하는 방법 #

Ingantt는 기기의 언어 설정(웹에서는 브라우저가 보고하는 언어)을 읽어 위 언어 중 하나이면 그 언어를 사용합니다. Ingantt 안에는 언어 설정이 없습니다. 인터페이스 언어를 바꾸려면 기기나 브라우저의 언어를 바꾼 다음 Ingantt를 다시 여십시오.

언어는 몇 가지 지역 기본값도 결정합니다. 시간을 12시간제로 표시할지 24시간제로 표시할지, 한 주가 어느 요일에 시작하는지, 새 프로젝트가 어떤 통화 기호로 시작하는지가 여기에 해당합니다. 이는 시작점일 뿐입니다. 날짜/시간 형식은 옵션 대화 상자에 있으며, 주의 시작 요일과 통화는 프로젝트에 속하므로 프로젝트 속성에서 설정합니다.

프로젝트의 언어 #

인터페이스 언어와 계획의 내용은 서로 독립적입니다. Ingantt 메뉴가 어떤 언어이든 작업 이름, 자원 이름, 메모 및 일정의 기타 텍스트는 원하는 언어로 입력할 수 있습니다.

통화와 통화 기호의 위치는 인터페이스 언어가 아니라 프로젝트 속성에서 프로젝트별로 설정합니다. 비용 계획을 참조하십시오.

이 도움말 센터 #

이 가이드는 영어, 독일어, 스페인어, 프랑스어, 이탈리아어, 포르투갈어, 우크라이나어, 일본어, 한국어로 게시됩니다. 헤더의 언어 전환기를 사용하십시오. 일부 최신 문서는 번역되기 전까지 영어로만 제공됩니다. 그러한 문서에서 언어를 전환하면 대신 해당 언어 가이드의 시작 페이지로 이동합니다.

Ingantt 인터페이스는 사용자의 언어로 제공되는데 이 가이드는 그렇지 않다면 알려 주십시오. 우선순위를 정하는 데 도움이 됩니다.
