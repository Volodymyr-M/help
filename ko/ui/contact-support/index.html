지원 문의

지원 문의 #

도움말 메뉴에는 두 항목이 나란히 있으며 서로 다른 역할을 합니다.

  • 도움말 → 지원 문의는 Ingantt 안에서 양식을 엽니다. 프로젝트 파일을 함께 보낼 수 있고, 사용 중인 플랫폼과 빌드를 저희에게 알려 줍니다. 계획에 문제가 있을 때 사용하는 항목입니다.
  • 도움말 → 이메일 지원은 support@ingantt.com을 수신자로 하여 사용자의 메일 클라이언트를 엽니다. 앱이 시작되지 않거나 자신의 메일함에서 직접 작성하고 싶을 때 사용하십시오.

앱에서 보고 보내기 #

도움말 → 지원 문의에는 다음이 표시됩니다:

  • 보낸 사람 — Google 계정 사진, 이름, 이메일이 자동으로 채워지며 편집할 수 없습니다. Google에 로그인되어 있어야 하며, 그렇지 않으면 양식이 열리지 않습니다.
  • 메시지 상자: 문제 또는 피드백을 설명하세요.
  • 체크박스: 현재 프로젝트 파일 포함.

보내기를 누르십시오. 성공하면 감사합니다! 이메일로 답변드리겠습니다.가 표시됩니다. 실패하면 전송에 실패했습니다. 다시 시도하거나 직접 이메일을 보내주세요.가 표시되며, 이 경우 이메일 지원을 대신 사용하십시오.

보고에는 실행 중인 플랫폼, 클라이언트 버전, 언어도 함께 담기므로 빌드를 따로 설명할 필요가 없습니다.

현재 프로젝트 파일 포함 #

체크박스는 처음에 해제되어 있습니다. 체크하지 않으면 파일이 전달되지 않습니다.

이 옵션은 열려 있는 프로젝트에 작업이 둘 이상 있을 때만 표시됩니다. 비어 있거나 막 만든 계획에는 보낼 만한 것이 없으므로 옵션이 아예 숨겨집니다.

체크하면 Ingantt가 계획을 프로젝트 이름의 XML로 첨부합니다. 저장하지 않은 편집 내용을 포함하여 지금 화면에 보이는 그대로 계획을 보냅니다. .mpp 파일을 열었더라도 저희가 받는 것은 원래의 .mpp가 아니라 Ingantt 자체 형식인 XML입니다.

일정에 관한 문제를 보고할 때는 반드시 체크해 주십시오. 날짜, 종속성, 달력, 제약 조건은 서로 영향을 주고받기 때문에, 사용자가 보고 있는 것을 저희가 확인하는 가장 빠른 방법은 대개 계획 자체입니다.

답변 #

양식의 보낸 사람 줄에 표시된 주소로 이메일로 답변드리므로 해당 메일함을 확인하십시오. 보고에는 참조 번호가 없으므로, 같은 문제로 다시 문의할 때는 두 문의를 연결할 수 있도록 같은 주소에서 보내 주십시오.
