지원 문의

오프라인으로 작업하기 #

의도적으로 저장하기 전까지 Google Drive에 아무것도 기록되지 않도록 자동 저장을 끕니다. 곧 연결이 끊길 예정일 때 유용합니다.

Web 버전에서는 메뉴 항목이 File → Work offline (no autosave)입니다. Windows, macOS, Android, iOS에서는 같은 스위치의 이름이 Enable autosave입니다.

Work Offline의 기능 #

File → Work offline은 현재 탭의 자동 저장을 끕니다. 그것이 전부입니다. 켜져 있는 동안 Ingantt는 20초마다 프로젝트를 Google Drive에 기록하는 것을 중단하며, 저장하기 전까지 브라우저 밖으로 아무것도 나가지 않습니다.

켜면 일회성 알림이 표시됩니다:

Offline mode is on. Remember to save your changes manually before closing the tab. (오프라인 모드가 켜져 있습니다. 탭을 닫기 전에 변경 사항을 직접 저장하십시오.)

이 말을 그대로 받아들이십시오. Ingantt는 편집 내용을 대기열에 넣지 않으며, 다시 온라인이 되어도 전송하지 않습니다. 백그라운드 동기화는 없습니다. 저장하지 않고 탭을 닫거나 새로 고치면 마지막 저장 이후의 작업은 사라집니다.

오프라인 상태에서 저장하기 #

연결 없이는 Google Drive에 저장할 수 없으므로, 다음 순서로 진행하면 됩니다:

  1. 아직 연결되어 있을 때 계획을 엽니다.
  2. File → Work offline을 켭니다.
  3. 평소처럼 편집합니다. 모든 것이 브라우저 안에서 이루어집니다. 일정이 다시 계산되고 실행 취소와 다시 실행이 작동하며, 아무것도 어디로도 전송되지 않습니다.
  4. 다시 온라인이 되면 Work offline을 다시 끈 다음 Save(또는 Ctrl/Cmd + S)를 누릅니다. 이 단계에서 작업 내용이 Drive에 저장됩니다.
  5. 그 시점부터 자동 저장이 재개됩니다.

4단계를 기억하는 데 의존하고 싶지 않다면 연결이 끊기기 전에 복사본을 내보내십시오. File → Export → XML은 계획을 기기에 다운로드하며, 나중에 그 파일을 다시 열 수 있습니다.

Save 버튼이 현재 상태를 알려 줍니다 #

도구 모음의 Save 버튼이 지켜봐야 할 표시기입니다:

표시 내용 의미
File saved to Google Drive 모든 것이 Drive에 있습니다.
Autosave pending… 저장되지 않은 편집 내용이 있으며, 곧 자동 저장이 처리합니다.
Saving… 저장이 진행 중입니다.
Save file to Google Drive 저장되지 않은 편집 내용이 있고 자동 저장이 꺼져 있습니다. 직접 저장해야 합니다.
Error saving file to Google Drive 저장을 시도했지만 실패했습니다. 편집 내용은 여전히 탭에 있으며 저장되지 않은 상태입니다.

연결이 끊긴 상태에서 자동 저장이 실행되면 이 오류 상태가 표시됩니다. 저장이 실패하고 버튼이 빨간색으로 바뀌며 프로젝트는 탭에 저장되지 않은 채로 남습니다. 그 순간 잃는 것은 없지만 안전한 것도 아닙니다. 다시 연결하고 저장하십시오.

플랫폼별 차이 #

  • Web에서는 이 설정이 유지되지 않습니다. 탭별, 세션별로 적용됩니다. 새 탭을 열거나 새로 고치면 자동 저장이 다시 켜집니다. 이는 의도된 동작입니다. 자동 저장이 켜진 상태가 더 안전한 기본값이므로, 끄는 것을 잊은 오프라인 스위치가 계속 따라다니지 않도록 한 것입니다. Windows, macOS, Android, iOS에서는 자동 저장 설정이 기억됩니다.
  • 기본값이 다릅니다. Web에서는 자동 저장이 기본적으로 켜져 있습니다. 데스크톱 및 모바일 빌드에서는 기본적으로 꺼져 있으며, 같은 메뉴 항목이 Enable autosave로 표시됩니다.
  • 아직 저장하지 않은 프로젝트는 오프라인 모드와 관계없이 전혀 자동 저장되지 않습니다. 자동 저장은 Drive에 이미 존재하는 파일만 업데이트할 수 있습니다. 한 번 저장하면 그다음부터 자동 저장이 맡습니다.
  • Web 버전에서 기기에서 연 파일은 절대 자동 저장되지 않습니다. Ingantt for Web은 디스크의 파일에 다시 쓸 수 없습니다. 자동 저장을 사용하려면 Google Drive에 저장하십시오.

오프라인 작업과 AI로 편집하기 #

자동 저장이 꺼진 상태에서 AI로 편집하기를 사용하면 Ingantt가 경고합니다. AI의 변경 사항은 열린 프로젝트에 실행 취소 가능한 일반 편집으로 적용되며, 저절로 저장되지는 않습니다. 저장하지 않고 탭을 닫으면 다른 수동 편집과 마찬가지로 AI의 작업도 함께 사라집니다.

지원되지 않는 기능 #

기대치를 분명히 하기 위해:

  • Ingantt는 오프라인이 되거나 다시 온라인이 되는 것을 감지하지 않습니다.
  • Ingantt는 오프라인에서 수행한 편집을 대기열에 넣었다가 다시 연결될 때 재생하지 않습니다.
  • 동기화가 없으므로 동기화 충돌 해결도 없습니다. 동료와 같은 Drive 파일을 함께 편집하면 마지막 저장이 우선합니다. 작업별로 병합되는 것이 아니라 파일 전체가 교체됩니다.
  • 계획을 처음 여는 데는 연결이 필요합니다. 오프라인 작업은 이미 열어 둔 계획을 계속 편집할 수 있게 할 뿐, 새 계획을 열 수 있게 하지는 않습니다.
