# 진행 추적

작업이 시작되면 각 작업의 **완료율**을 업데이트하여 실제 진행 상황이 계획과 어떻게 비교되는지 추적합니다. **프로젝트 업데이트**를 사용하여 진행 상황을 일괄 설정합니다. 진행 상황이 기록되면 Ingantt가 자동으로 [실적](/ko/tracking/actuals/index.md)을 계산합니다 — 기간, 작업량, 비용 및 날짜에 대한 실적 및 잔여 값입니다.

## 완료율

프로젝트가 실행 중이면 진행 상황을 추적해야 합니다. 각 작업의 **완료율**을 최신 상태로 유지하면 루트 요약 작업에서 프로젝트의 전체 **완료율**을 확인할 수 있습니다.

**작업 속성** 대화 상자의 **완료율** 필드를 사용하여 특정 작업의 완료율을 설정합니다. 100% 완료된 작업은 작업 목록에 녹색 체크 표시 아이콘이 표시됩니다.

완료율을 업데이트할 때:

- 0% 이상으로 설정하면 작업의 **실제 시작**이 작업의 예정 시작 날짜로 설정됩니다.
- 100%로 설정하면 작업의 **실제 완료**가 작업의 예정 완료 날짜로 설정됩니다.
- **실제 기간**과 **남은 기간**은 완료율을 기반으로 자동 계산됩니다.
- 프로젝트 설정에서 **작업 상태 업데이트 시 자원 상태도 업데이트**가 활성화(기본값)되어 있으면 **실제 작업**과 **남은 작업**도 비례적으로 업데이트됩니다.

요약 작업의 **완료율**은 모든 하위 비요약 작업의 기간 가중 평균으로 계산됩니다.

> [프로젝트 업데이트](#프로젝트-업데이트) 명령을 사용하여 기준 날짜를 기반으로 여러 작업의 완료율을 한 번에 설정할 수도 있습니다.

## 프로젝트 업데이트

**프로젝트 업데이트** 명령은 **프로젝트** 메뉴에서 접근할 수 있는 일괄 진행 추적 작업을 제공합니다.

### 작업을 완료로 업데이트

지정된 날짜까지 작업을 완료로 표시합니다:

- **비례 (0%~100%)** — 각 작업의 근무 기간 중 기준 날짜 이전에 해당하는 부분을 기반으로 완료율을 계산합니다.
- **전부 또는 전무 (0% 또는 100%)** — 기준 날짜까지 완료 여부에 따라 작업을 0% 또는 100%로 설정합니다.

### 미완료 작업 재예약

미완료 작업을 지정된 날짜 이후에 시작하도록 이동합니다:

- 시작되지 않은 작업은 **이전에는 시작 불가** 제약 조건을 받습니다.
- 진행 중인 작업은 프로젝트 일정 옵션에서 **진행 중인 작업 분할**이 활성화된 경우 분할됩니다.
- 완료된 작업은 수정되지 않습니다.
