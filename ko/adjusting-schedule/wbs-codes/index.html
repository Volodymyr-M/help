지원 문의

WBS 코드 #

모든 작업에는 개요에서의 주소인 WBS 코드가 있습니다. 기본적으로 이는 단순한 개요 번호(1, 1.1, 1.2, 1.2.1)입니다. 작업 테이블에서 WBS 열을 켜면 표시됩니다.

WBS 코드 마스크는 이러한 개요 번호를 직접 설계한 구조화된 코드로 대체하므로, 작업이 1.1.1 대신 PROJ-A-01이나 1.A.001로 표시됩니다. 계약, 비용 코드 체계, 고객의 보고 형식 등 번호 부여 표준이 있는 조직에서는 이를 사용하여 Ingantt의 코드를 그 표준에 맞춥니다.

설정하려면 프로젝트 → WBS 코드 정의를 여십시오.

WBS 코드와 개요 코드는 다릅니다 #

  • WBS 코드는 구조적입니다. 작업당 정확히 하나씩 있으며 작업이 개요에서 차지하는 위치에서 파생됩니다. 작업을 이동하면 자동으로 번호가 다시 매겨집니다.
  • 개요 코드는 태그입니다. 부서, 단계, 비용 센터 등의 조회 목록을 정의하고 계층 구조와 무관하게 작업에 값을 지정합니다. 하나의 작업이 여러 개요 코드에서 여러 값을 가질 수 있습니다.

마스크 정의 #

대화 상자는 세 부분으로 구성됩니다.

프로젝트 코드 접두사 #

프로젝트의 모든 코드 앞에 붙는 고정 텍스트입니다. 접두사가 PROJ이면 구분 기호에 따라 코드가 PROJ.1.1 또는 PROJ-A-01로 표시됩니다. 접두사를 사용하지 않으려면 비워 두십시오.

코드 마스크 #

수준 추가로 추가하는 개요 수준당 한 행입니다. 각 행에서 다음을 설정합니다:

필드 역할
수준 이 행이 적용되는 개요 깊이입니다. 수준 1은 최상위 작업, 수준 2는 그 하위 작업이며, 이런 식으로 이어집니다.
순서 이 수준에서 사용하는 문자입니다: 숫자(1, 2, 3), 대문자(A, B, C … Z, AA), 소문자(a, b, c … z, aa) 또는 문자.
길이 이 수준의 최대 문자 수입니다. 비워 두면(제한 없음으로 표시됨) 제한이 없습니다.
구분자 이 수준과 다음 수준 사이의 문자입니다(예: . 또는 -).

필드 동작에 관해 알아 둘 두 가지가 있습니다:

  • Length는 숫자 앞에 0을 채웁니다. Numbers 수준에서 길이가 3이면 아홉 번째 작업은 009가 됩니다. 문자 수준에는 채우지 않습니다.
  • 문자는 Ingantt가 생성하는 코드에서는 Numbers와 똑같이 동작합니다. 이 옵션은 직접 입력하는 수준을 뜻하는 Microsoft Project와의 호환성을 위해 존재합니다.

모든 수준을 정의할 필요는 없습니다. 마지막 마스크 행보다 깊은 수준은 . 구분 기호가 있는 숫자로 대체되므로, 다섯 단계 깊이의 계획에 세 행짜리 마스크를 적용해도 완전한 코드가 생성됩니다.

옵션 #

새 작업에 WBS 코드 생성과 새 WBS 코드의 고유성 확인은 프로젝트와 함께 저장되며 Microsoft Project 왕복 과정에서도 유지됩니다. Ingantt에서는 수준이 하나 이상인 마스크가 모든 작업에 자동으로 적용되며, 코드는 개요를 따르므로 구조상 고유합니다.

마스크를 저장하면 일어나는 일 #

Ingantt는 즉시 프로젝트 전체의 번호를 다시 매깁니다. 코드는 작업을 추가, 삭제, 들여쓰기, 내어쓰기 또는 이동하는 등 구조가 바뀔 때마다 개요에서 다시 생성되므로 항상 작업의 현재 위치를 나타냅니다.

이 점은 분명히 말해 둘 필요가 있습니다. WBS 코드는 작업의 영구적인 식별자가 아닙니다. 작업을 이동하면 코드가 바뀝니다. 작업을 따라다니는 레이블이 필요하다면 개요 코드나 사용자 정의 텍스트 필드를 대신 사용하십시오.

가져오기 및 내보내기 #

마스크는 Microsoft Project 형식의 일부이며 왕복 과정에서 유지됩니다. 마스크와 함께 가져온 프로젝트는 마스크를 유지하고, 마스크와 함께 내보내지며, 작업 코드는 Microsoft Project가 생성한 것과 일치합니다.
