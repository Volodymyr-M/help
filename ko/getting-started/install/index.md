# Ingantt for Web 열기

Ingantt for Web은 브라우저에서 실행됩니다. 다운로드하거나 설치할 것이 없습니다. [web.ingantt.com](https://web.ingantt.com){:target="_blank"}을 열고 바로 작업을 시작하십시오. 프로젝트는 Microsoft Project와 완전히 호환되는 형식으로 저장되므로 Microsoft Project를 사용하는 누구와도 파일을 주고받을 수 있습니다.

## 계정 유무에 관계없이 사용하기

로그인하지 않아도 Ingantt for Web을 사용할 수 있습니다. 기기에서 프로젝트 파일을 열고, 편집한 다음, 결과를 다운로드하십시오.

Google로 로그인하면 Ingantt for Web이 프로젝트를 내 Google Drive에 보관하고, 작업 중에 저장하며, 다른 사람과 공유할 수 있습니다. [Google Drive 연동](/ko/ui/files/index.md) 및 [프로젝트 공유](/ko/ui/sharing/index.md)를 참조하십시오.

## Google Drive에 Ingantt for Web 추가하기

Ingantt for Web은 [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/gantt_chart_ai_project_planning_ingantt/286119906331){:target="_blank"}에 등록되어 있습니다. 거기에서 추가하면 Google Drive의 **New** 메뉴와 Ingantt 파일의 **Open with** 메뉴에 **Ingantt**가 표시되어 Drive에서 바로 프로젝트를 만들고 열 수 있습니다. 자세한 내용은 [Google Drive 연동](/ko/ui/files/index.md)을 참조하십시오.
