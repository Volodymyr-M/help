지원 문의

프로젝트 템플릿 #

템플릿은 복사해서 편집하는 기성 계획입니다. 작업, 기간, 종속성, 개요가 이미 갖춰진 상태로 제공되므로 처음부터 입력하는 대신 구조를 다듬기만 하면 됩니다.

기본 제공 템플릿 #

네 가지 템플릿이 기본으로 내장되어 있습니다. 다운로드할 것도, 템플릿 스토어도 없습니다.

템플릿 용도
Tutorial Template Ingantt의 기능을 안내하는 가이드 계획입니다. 앱이 처음이라면 가장 좋은 첫 프로젝트입니다.
PMI Process Template PMI 프로세스 그룹(착수, 기획, 실행, 감시 및 통제, 종료)을 작업 개요로 구성한 것입니다.
Software Development Plan Template 요구 사항, 설계, 구축, 테스트, 릴리스로 이루어진 소프트웨어 배포 계획입니다.
Wedding Plan Template 확정된 마감일이 있는, 소프트웨어가 아닌 분야의 실제 예시입니다.

템플릿으로 계획 시작하기 #

프로젝트 화면에서. 상단의 Start a new project plan 띠에 각 템플릿이 미리보기 이미지와 함께 표시됩니다. 하나를 클릭하면 열립니다. 그 옆의 + 카드는 대신 Blank project plan을 시작합니다. Template gallery는 전체 목록을 대화 상자로 열고, ⋮ 메뉴에는 띠를 보고 싶지 않을 때 쓰는 Hide all templates가 있습니다.

프로젝트 안에서. File → New from template을 선택하십시오.

어느 쪽이든 복사본을 얻게 됩니다. 기본 제공 템플릿 자체는 절대 수정되지 않으므로 같은 템플릿에서 원하는 만큼 자주 시작할 수 있습니다.

새 계획이 저장되는 위치 #

Ingantt를 어떻게 실행하는지에 따라 다릅니다.

  • Google에 로그인한 Ingantt for Web. 새 계획은 즉시 Google Drive에 기록되고 새 브라우저 탭에서 열립니다. 작업 중이던 프로젝트는 원래 탭에서 그대로 열려 있습니다. 처음부터 Drive에 있으므로 자동 저장이 즉시 켜집니다.
  • 그 밖의 모든 경우. 계획은 저장되지 않은 프로젝트로 열립니다. 저장하기 전까지는 저장 위치가 없고 자동 저장도 되지 않으므로, Save 또는 Save as를 사용하여 저장 위치를 선택하십시오.

템플릿을 읽을 수 없으면 Error loading template. Please try again.이 표시됩니다. Drive에 기록할 수 없으면 Error saving to Google Drive.가 표시됩니다. 두 경우 모두 아무것도 변경되지 않았으며 기존 프로젝트에는 영향이 없습니다.

템플릿이 열린 후 #

복사본은 일반 프로젝트입니다. File → Rename으로 이름을 바꾸고, 필요 없는 작업을 삭제하고, 프로젝트 속성에서 프로젝트 시작 날짜를 설정하십시오. 템플릿의 날짜는 자체 시작일을 기준으로 하므로 시작 날짜를 바꾸면 모두 함께 이동합니다.

템플릿으로 새 프로젝트를 시작하려면 빈 프로젝트를 만들 때와 마찬가지로 활성 체험 또는 구독이 필요합니다.
